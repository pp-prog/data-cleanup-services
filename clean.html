在线表格清洗（浏览器本地版）

把乱糟糟的供应商表 / 客户表 / 订单表洗成 干净表 + 待复核表 + 处理报告。 不用装环境、不用注册、不用下载，文件全程不离开你的电脑。
纯本地运行 · 零上传行数守恒 · 不静默丢行 修不好的单独列出来免费

2 · 结果

它到底做了什么

  • 自动认表头：供应商 / 公司 / Vendor → 姓名；邮箱 → email；金额 / 应付金额 → amount…
  • 日期归一：2024/1/5、2024年1月5日、Jan 8 2024 → 2024-01-05
  • 金额归一：240 USD、1.234,56（欧式）、1,234.50（美式）、(240)（负数）
  • 邮箱校验：大小写归一；非法邮箱不猜，直接进复核表
  • 电话清洗：+81 (0)90-1234-5678 ext.22 → 8109012345678
  • 币种识别：¥ € $ USD CNY → ISO 代码
  • 去重合并：同邮箱或同电话视为同一主体，合并并记录合并了几行
  • 行数守恒：入 = 干净 + 待复核 + 合并，一行都不会悄悄消失

三条原则

  • 不编造数据 —— 修不好的值不猜，落到复核表里让你看见。
  • 不静默丢行 —— 每一行要么进干净表，要么进复核表。
  • 不覆盖原文件 —— 你的原表永远不动。
